\newglossaryentry{decay0}{name={Decay0}, description={is a program written in the early 90's by Volodymyr Tretyak and collaborators, using the Fortran 77 programming language and the CERNLIB library. It has been maintained and improved up to 2020. Later, a pure C++ version was released without any dependency on Fortran and CERNLIB. This code was integrated in 2011 as the genbb\_help module of the Bayeux C++ library (version < 4). BxDecay0 is a standalone library with very few dependencies (mostly the GSL library for numerical integration and a few special math functions). External random engines can be used through a simple wrapping functor interface, particularly the ones provided by the C++ standard random library can be used by default. However the user is free to provide its own uniform deviates random generator (based on GSL, ROOT or whatever).}}

\newglossaryentry{marley}{name={MARLEY}, description={(Model of Argon Reaction Low Energy Yields) is a neutrino event generator designed to simulate low-energy neutrino interactions with argon nuclei. It is developed by the Low-Energy Neutrino group of the DUNE collaboration. MARLEY focuses on simulating interactions relevant to solar and supernova neutrinos in liquid argon detectors, providing detailed modeling of the nuclear physics involved in these interactions. It incorporates a gamma-decay scheme to describe the de-excitation of the residual nucleus after a neutrino interaction, which is crucial for accurately simulating the resulting signals in the detector. MARLEY is implemented in C++ and is designed to be integrated with the LArSoft framework used by the DUNE collaboration for detector simulation and event reconstruction.}}
